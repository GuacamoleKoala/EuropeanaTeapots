# INFO ON FOLDER 'PREVIEW_IMAGES_TEAPOTS_DATASET'

This folder contains the collection of preview images or thumbnails of the dataset of teapots on Europeana.
In chapter four I wrote a script that downloads all the thumbnails into a folder.
This helps to quickly check what items or records really are teapots and not something else.

Github did not allow to upload files bigger than 25mb. For that reason I divided the collection of thumbnails into segments of 1000 images. This creates the files '1-1000', '1001-2000', and so on.

Because the naming of the images was arbitrary, I decided to name them 'image 1' to 'image x'. I kept a log of the naming and the connection to the rest of the record in the file 'image_download_log'. This way images can easily be retraced to the original record.
