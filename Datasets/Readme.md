# INFO ON FOLDER 'DATASETS'

This readme explains the contents of the folder 'Datasets'.

1) 'Dataset_initial_notcleaned' contains the dataset that is retrieved from chapter one.
Prompting Gemini and Chatgpt resulted in a Python script that can download almost all metadata
regarding queries about teapots (translations, spelling variations, etc).

2) the second dataset contains an addition of fields that I retrieved in chapter one. Again I created a Python script
that can download certain metadata fields that were lacking in the first dataset.

3) the third dataset 'DatasetCleanedEuropeanaTeapot' is a cleaned version after all kinds of operations
in OpenRefine and in Excell.

4) the fourth dataset 'TeapotDatasetEuropeanaTableau' is a cleaned version after all kinds of operations in OpenRefine, Excell (see earlier 3)
and extra cleaning/renaming during visualisations in Tableau.
